# Academy

Веб-платформа для организации обучения программированию.

Преподаватель может создавать курсы, объединять учеников в группы, публиковать учебные темы и задания. Ученик проходит материалы, пишет решения непосредственно в браузере и отправляет их на проверку.

## Идея

Основная сущность платформы — курс, состоящий из учебных тем и практических заданий.

```text
Преподаватель
     │
     ├── Курс
     │    ├── Учебная тема
     │    ├── Классная работа
     │    └── Самостоятельная работа
     │             │
     │             └── Задания
     │                  └── Test Cases
     │
     └── Группы учеников
```

Для задач по программированию преподаватель может задать входные и выходные данные, ограничения и тест-кейсы. Решение ученика сохраняется как отдельная попытка с результатом проверки.

Поддерживаются статусы успешного решения, неверного ответа, синтаксической ошибки, превышения лимита времени и ручной проверки.

## Архитектура

Проект разделен на независимые frontend и backend:

```text
┌──────────────────────────────┐
│          Next.js             │
│                              │
│ UI / CodeMirror / страницы   │
└──────────────┬───────────────┘
               │ HTTP / JSON
               ▼
┌──────────────────────────────┐
│     Django REST Framework    │
│                              │
│ users / courses / classes    │
│ JWT authentication           │
└──────────────┬───────────────┘
               │
               ▼
        ┌─────────────┐
        │    MySQL    │
        └─────────────┘
```

Авторизация построена на JWT. Access и refresh token передаются через cookies, а API разделено на модули пользователей, курсов и учебных групп.

## Основные сущности

**User** — базовый пользователь системы. Авторизация выполняется по email.

**Student / Teacher** — профили ученика и преподавателя.

**Course** — учебный курс, принадлежащий преподавателю.

**Topic** — раздел курса. Может быть учебной темой, классной или самостоятельной работой.

**Task** — практическое задание внутри темы.

**TestCase** — набор входных и ожидаемых выходных данных для автоматической проверки решения.

**Attempt** — решение, отправленное учеником.

**Group** — учебная группа, связывающая преподавателя, учеников и курс.
